Tugas Eksperimen Modul Node.js

Repository ini berisi hasil pengerjaan aktivitas pembelajaran menggunakan JavaScript dan Node.js.

Daftar Aktivitas

Aktivitas 1: Modul Buatan Sendiri

Membuat modul "getDiscount.js" untuk menghitung harga setelah diskon dan memanggilnya melalui "index.js".

Aktivitas 2: Modul Inti Node.js

Menggunakan modul "os" untuk memperoleh informasi sistem dan modul "url" untuk mengambil parameter URL melalui "index2.js".

Aktivitas 4: Mini App Modular

Membuat aplikasi konversi suhu Celsius ke Fahrenheit menggunakan modul "rumusSuhu.js" dan program utama "konversiSuhu.js".

Teknologi

- JavaScript
- Node.js
- CommonJS
- Chalk

Cara Menjalankan

Jalankan program melalui terminal:

node index.js
node index2.js
node konversiSuhu.js

Untuk memasang dependensi aplikasi:

npm install

Tujuan

Memahami penggunaan modul buatan sendiri, modul inti Node.js, dan package eksternal dalam aplikasi sederhana.
